# 🤖 ChatMech - Assistente Virtual Automotivo

Solução inteligente de atendimento virtual voltada para o setor automotivo, com foco em diagnósticos veiculares, histórico de manutenções, agendamento em oficinas e suporte completo por meio de um chatbot chamado **Mechzinho**.

---

## 📌 Descrição do Projeto

O **ChatMech** é um sistema completo que integra tecnologias de inteligência artificial, interface conversacional e gerenciamento de dados para proporcionar uma experiência digital moderna na manutenção de veículos. Com foco em acessibilidade e usabilidade, a plataforma oferece desde diagnósticos automatizados até o agendamento em oficinas mecânicas, tudo com o apoio do assistente virtual Mechzinho.

---

## 🎯 Objetivos

- Oferecer diagnósticos automotivos simples e rápidos por meio de chat.
- Disponibilizar o **histórico de manutenções** de veículos para usuários.
- Facilitar o **agendamento de serviços** em oficinas mecânicas.
- Promover **atendimento acessível**, com suporte por voz e visual.
- Centralizar informações de veículos, usuários e atendimentos.
- Garantir uma jornada completa e personalizada para cada motorista.

---

## 🔧 Componentes da Solução

### 1. Chatbot Mechzinho
- Interface de atendimento por texto.
- Fluxos definidos para diagnósticos, histórico e agendamentos.
- Utilização de regras e, futuramente, modelos de machine learning.

### 2. Backend em Python
- API RESTful para gerenciar usuários, veículos, agendamentos e histórico.
- Integração com banco de dados Oracle.
- Acesso a APIs externas como ViaCEP e OpenWeather.

### 3. Inteligência Artificial
- Classificação e resposta com TF-IDF + árvore de decisão.
- Dataset de conversas simuladas com fins de aprendizado supervisionado.
- Pipeline de pré-processamento, treino e avaliação.

### 4. Frontend com Interface Web
- Cadastro e edição de veículos.
- Exibição de resultados do chatbot.
- Responsivo e acessível.

### 5. Organização por Sprints
- SPRINT 1 a SPRINT 4 documentam a evolução contínua do projeto.
- Cada sprint contém códigos, notebooks e validações dos objetivos.

---

## 📈 Escalabilidade e Visão Futuro

- Integração com reconhecimento de voz para ampliar acessibilidade.
- Aplicação de modelos mais robustos de NLP como BERT.
- Expansão para atender oficinas parceiras e integração com ERPs.
- Painel administrativo com visualização de métricas e atendimentos.
